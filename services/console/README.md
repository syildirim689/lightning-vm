# Console gateway — henüz uygulanmadı
Hedef: VMware WebMKS için ayrı WebSocket geçidi.

Önce kullanıcı/sunucu sahipliği veya yönetici yetkisi kontrol edilir.
Tek kullanımlık, kısa ömürlü oturumla erişilir; konsol biletleri loglanmaz.
Origin kontrolü, oturum iptali, bağlantı sınırı ve denetim kaydı gerekir.
VMware yönetim ağı tarayıcıya açılmaz. ESXi/vCenter sürümünde gerçek bağlantı testi gerekir.

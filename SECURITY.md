# Güvenlik
Bu başlangıç sürümü üretim için uygun değildir. Henüz kullanıcı kimlik doğrulaması yoktur.
Güvenlik açıklarını sır veya istismar ayrıntılarıyla herkese açık issue olarak paylaşmayın.
Depo sahibi GitHub Private Vulnerability Reporting özelliğini açtıktan sonra özel bildirim kullanın.
Bu özellik henüz açılmadıysa depo sahibinden özel bildirim kanalı isteyin.
